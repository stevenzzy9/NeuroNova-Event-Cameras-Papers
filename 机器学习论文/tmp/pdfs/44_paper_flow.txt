Abstract

With their high dynamic range and temporal resolution,
event cameras are well-suited for object detection, especially under motion blur and extreme illumination. Recent
state-of-the-art works for event-based object detection primarily focus on the high-level design of backbones. However, developing effective event representations is equally
crucial, as it bridges asynchronous event streams with the
dense tensors required by detection networks. Most existing aggregation strategies for event representation continuously accumulate all events within sampled intervals without selective filtering, inevitably introducing uninformative
events that degrade detection accuracy. To address this limitation, we introduce a novel perspective, termed Discrete
Aggregation, which adaptively and discretely selects informative events for differentiable aggregation. We realize this
through the Spiking Discrete Aggregation (SDA) module,
which is inspired by the threshold-based spike firing mechanism in Spiking Neural Networks (SNNs) and implemented
using gated recurrent spiking neurons. Additionally, we introduce the Multi-Timescale Fusion (MTF) method which
leverages coarse-grained temporal features from continuous event streams to further enhance the representation
capability of SDA. Experimental results on neuromorphic
datasets demonstrate that our method achieves state-of-theart performance among all fully spiking architectures while
using fewer parameters, reaching 43.4% mAP50:95 on Gen1
(+ 4.5% over prior art). Moreover, our method exhibits superior robustness under noisy conditions and shows strong
compatibility with non-spiking models.

and then aggregating events within each interval into dense
tensors. We notice that existing event aggregation methods [3, 8, 18, 20, 24, 25, 36] integrate all events occurring
within the sampled interval without any selective filtering,
as shown in Fig. 1A. For example, ASTMNet [18] employs

when an event does not activate the neuron to fire a spike.
We refer to this continuous accumulation of events over
time as continuous aggregation. This process inevitably embeds redundant or irrelevant events (e.g., sensor-induced artifacts and motion-related blur [12, 37]). To address this
limitation, we propose a novel perspective: discrete aggregation, which adaptively and discretely retains informative
events, unlike continuous aggregation (see Fig. 1A). Moreover, the aggregation mechanism can be optimized using
high-level semantics from downstream networks.
To implement this idea, we propose the Spiking Discrete Aggregation (SDA) module, inspired by the spikefiring mechanism of Spiking Neural Networks (SNNs). In
SNNs, a spike is generated only when the membrane potential reaches a certain threshold, which naturally aligns
with discrete aggregation: irrelevant events fail to trigger
spikes due to insufficient membrane potential accumulation,
whereas informative events can activate spiking neurons.
SDA employs pixel-wise gated recurrent spiking neurons
to aggregate events that cause their corresponding neurons
to fire spikes, and it can be optimized by downstream fully
spiking detectors.
Although SDA excels at fine-grained event selection,
event-based object detection also requires multi-timescale
feature modeling, since the temporal density of events generally correlates with object motion speed (e.g. faster objects generate denser events, whereas slower ones result in
sparser event distributions). Therefore, we introduce the
Multi-Timescale Fusion (MTF) method, which incorporates
coarse-grained temporal information from extended time
intervals to enhance the representation learned by SDA. As
shown in Fig. 1B, our detector equipped with SDA-MTF
achieves superior performance while using fewer parameters compared to other fully spiking detectors.
The main contributions are summarized as follows:
• We propose a novel spike-driven discrete aggregation
module for event-based object detection, implemented
with gated recurrent spiking neurons. This module tightly
couples the spike-firing mechanism of spiking neurons
with the adaptive aggregation of informative events.
• We introduce the Multi-Timescale Fusion (MTF) method,
which captures coarse-grained temporal features to enhance the representation capability of SDA.
• Our proposed method outperforms state-of-the-art fully

spiking detectors on the Gen1, 1Mpx and N-Caltech101
datasets, while achieving 3.79× higher energy efficiency
compared to ANNs. In addition, its effectiveness is further validated on various non-spiking architectures and
under noisy conditions.

2. Related Work
2.1. Event Representation
Existing event representations can be broadly categorized
into handcrafted and learning-based. Handcrafted methods,
such as Event Count [25], Voxel Cube [8] and Time Surface [33], apply predefined rules [1, 20, 26, 31] to continuously convert event streams into dense formats, suffering from noise sensitivity and lack of adaptability. A
notable exception is HOTS [17], which operates in a discrete manner by selectively extracting spatiotemporal features via a time-surface decay mechanism. However, its
non-differentiable nature prevents end-to-end optimization.
On the other hand, learning-based methods leverage neural networks to adaptively generate representations through
data-driven optimization. This category encompasses (1)
sparse representations, such as GNN-based [19, 32] and
SNN-based [36, 41], whose sparse computational properties enable lower energy consumption but lead to poor performance; (2) dense representations [3, 18] which recently
use temporal architectures to effectively extract spatiotemporal features, yet suffer from accumulation of uninformative events due to continuous aggregation. In this work,
we propose a novel differentiable discrete aggregation approach that addresses these limitations by leveraging the
spike-driven nature of SNNs.

2.2. Event-based Object Detection with SNNs
SNNs have been increasingly adopted in event-based object
detection. EMS-ResNet [34] designs a full-spike residual
block for detection. SpikeYOLO [23] explores a suitable
detection architecture and proposes an SNN with integervalued training and spike-driven inference. These works
focus on architectural design but do not explicitly address effective low-level processing of event data. EASSNN [36] adaptively samples events between spike firing
times for representation to mitigate the temporal mismatch
between the raw event stream and SNNs. CREST [24] introduces a conjointly trained spike-driven framework with
multi-scale spatiotemporal event representation for efficient
event-based object detection. However, they still include
uninformative events during continuous aggregation.

4. Method
Our motivation is to design a differentiable aggregation
module that can (1) discretely and adaptively aggregate informative events after sampling, (2) fully exploit spatiotemporal correlations in event data, and (3) effectively capture
temporal features across multiple timescales to further enhance the representation capability. Sections 4.1 to 4.3 detail these points. Fig. 2A shows an overview of the pipeline.

4.2. Gated Recurrent Spiking Neuron
Effective spiking discrete aggregation in event-based detection requires the ability to assign appropriate importance to events across time, especially under noisy or sparse
conditions. However, LIF neurons rely solely on simple
integrate-and-fire dynamics, lacking the capacity to adaptively capture complex temporal dependencies. To address
this limitation, we enhance LIF neurons by incorporating
recurrent connections and gating mechanisms.
We replace the constant decay factor τ in the LIF neuron
(as shown in Eq. (4)) with a learnable reset gate R, allowing the neuron to adaptively control the influence of past
membrane potential states on the present update:
  \label {eq:gate_u} \bm {u}_{t}(x,y,p) = \bm {R}_{t}(x,y,p) \cdot \bm {\hat {u}}_{t-1}(x,y,p) + \bm {I}_t(x,y,p)  (9)

4.1. Spiking Discrete Aggregation
In this section, we introduce Spiking Discrete Aggregation
(SDA), a differentiable module that links spike firing to discrete aggregation.
In SDA, a LIF neuron is assigned to each spatial coordinate and polarity combination (x, y, p), ensuring typical
aggregation behaviors. Given a sampled event set Ê, an
incoming event is selected for aggregation only if it drives
its corresponding neuron to fire a spike. Aggregation is then
achieved by accumulating the membrane potential u of each
event in the selected event set.
Since spikes are triggered by the dynamic evolution of
membrane potential, selection and aggregation in SDA are
naturally coupled into a unified operation:
  \label {eq:sampledevents} \hat {E}(x, y, p) = \{e_i| (x_i, y_i, p_i)=(x, y, p) \, \land \, e_i \in \hat {E} \}  (7)

where · denotes element-wise multiplication. When Rt
close to 0, prior state information is discarded, effectively
filtering out accumulated noise.
In addition, we also introduce gating and recurrent connections on the input current:
  \label {eq:gate_i} \begin {aligned} & \bm {I}_{t}(x, y, p) = \bm {F}_{t}(x,y,p) \cdot \bm {I}_{t-1}(x,y,p) + \bm {c}_{t}(x,y,p) \\ & \bm {c}_{t}(x, y, p) = {W}_I^q \bm {q}_{t}(x,y,p) + {W}_I^s \bm {s}_{t-1}(x,y,p) \end {aligned} 

(10)

where st−1 is the spike output at the last time step, and
F denotes the forget gate that modulates how much of the
previous input current should be retained. WIq and WIs are
learnable weights applied to the input qt and the previous
spike st−1 , respectively.
The reset gate R and forget gate F are computed as follows, allowing the neuron to modulate both internal mem-

4.3. SDA with Multi-Timescale Fusion
Given the importance of multi-timescale features in eventbased object detection, we propose the Multi-Timescale Fusion (MTF) method, which enhances SDA by incorporating
coarse-grained temporal information.
The coarse-grained temporal features (additional
timescales) are supported by SCA with adaptive sampling
(SAS). For detailed methodology, please refer to Wang
et al. [36]. In brief, SAS samples and continuously
aggregates events between two adjacent spike firing times,
tj−1 (x, y, p) and tj (x, y, p). The sampled event set is
formulated as follows:

 \label {eq:condition} \hat {E}^A_j(x,y,p) = \left \{ e_i \,\middle |\, \begin {aligned} & t_i \in \big [t_{j-1}(x, y, p), t_j(x, y, p)\big ] \\ & \land (x_i, y_i, p_i) = (x, y, p) \end {aligned} \right \} 
(12)
Within each sampled interval, both SDA and SAS perform their respective operations, and the output of SAS is
computed as follows:
  \label {CDA-MS} f_{SAS}(x, y, p) = \sum _{\substack { e_i \in \hat {E}^A_j(x,y,p)}} \bm {u}_{t_{i}}(x_i, y_i, p_i)

5. Experiments
5.1. Experimental Setup
Datasets. We evaluate our model on three event-based
datasets: Gen1 [9], 1Mpx [29] and N-Caltech101 [30]. The
Gen1 dataset is a widely used benchmark for event-based
object detection, recorded with a 304×240 resolution event
camera. The 1Mpx dataset comprises 14.65 hours of highresolution event recordings at 1280×720 pixels. The NCaltech101 is a neuromorphic version of the Caltech101,
comprising 8,709 event streams across 101 object categories, each annotated with a single bounding box.
Implementation Details. We train all models using the
Adam optimizer with an initial learning rate of 0.002 and a
cosine decay schedule. Dataset preprocessing and augmentation follow prior works RVT [11] and EAS-SNN [36]. For
Gen1, we use the event stream within 240 ms before each
annotation; for 1Mpx, we adopt the 3 segments provided by
RVT. Our detection framework uses fully spiking (We define “fully spiking” as the setting where all neurons in the
pipeline are spiking neurons) implementations of YOLOXM (25.3M) and YOLOX-S (8.9M), where the Backbone,
FPN, and Head are built using P-LIF and SEW-Residual
blocks with 3 time steps, consistent with EAS-SNN. All
models are evaluated using COCO mAP50:95 and mAP50 .

5.5. Energy Efficiency Analysis

6. Conclusion
This work proposes a novel event aggregation method,
Spiking Discrete Aggregation (SDA), for event-based object detection. Built by gated recurrent spiking neurons,
SDA exploits the spike-firing mechanism of SNNs to adaptively aggregate informative events. Enhanced by coarsegrained temporal context via Multi-Timescale Fusion, SDA
produces robust representation to improve detection accuracy. Experiments on the three neuromorphic datasets show
that SDA and SDA-MTF outperform existing fully spiking
models while using fewer parameters. Ablation studies further confirm that the performance gains stem from the SDA
mechanism itself. Moreover, we demonstrate their compatibility with ANNs and robustness under noisy conditions.

SNNs utilize binary spikes, leading to energy-efficient accumulation (AC) operations on neuromorphic hardware, unlike the dense multiplication-and-accumulation (MAC) operations used by ANNs. Notably, since the recurrent connections inside spiking neurons and the soft mask in MTF
introduce extra computation, we estimate their energy using
the same cost as a MAC operation. The detailed calculations are shown in the supplementary material.
